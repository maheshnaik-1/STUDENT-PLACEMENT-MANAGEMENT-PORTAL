# STUDENT PLACEMENT MANAGEMENT PORTAL
## How to Start the Project

Last verified: 5 November 2026

Project Location:
D:\Student Placement Management Portal

### STEP 1: Verify MySQL 8.0 Database

The Java Spring Boot backend connects to the MySQL 8.0 database (`placement_portal_java`).
Ensure MySQL 8.0 is running on your machine:

Open PowerShell and check the service status:

Get-Service MySQL80

If the status is Running, continue to Step 2.

If the status is Stopped, open PowerShell as Administrator and run:

Start-Service MySQL80

(Or ensure your MySQL 8.0 server instance is active on port 3306).

### STEP 2: Start the Java Spring Boot Backend

Open Terminal 1 in VS Code or Antigravity and navigate to the backend directory:

cd "D:\Student Placement Management Portal\server-java"

Configure the required environment variables in your terminal session before launching:

$env:JWT_SECRET = "<your_jwt_secret>"
$env:PLACEMENT_APP_PASSWORD = "<your_mysql_password>"

(Note: Do not hardcode or commit secret values. Replace the placeholders with your actual local configuration.)

Start the Spring Boot backend:

.\mvnw.cmd spring-boot:run

Keep this terminal open.

Backend Port: 5000

Port Collision Tip:
If an error appears indicating that port 5000 is already in use (e.g. Address already in use: bind), check whether the Spring Boot backend is already running in another terminal or background process before attempting to start another one.

### STEP 3: Start the React Frontend

Open Terminal 2 in VS Code or Antigravity and navigate to the client directory:

cd "D:\Student Placement Management Portal\client"
npm run dev

Keep this terminal open.

Frontend Port: 3000
Frontend URL:
http://localhost:3000

### STEP 4: Open the Application

Open your web browser and visit:

http://localhost:3000/login

Log in using your existing credentials.

### IMPORTANT NOTES

1. Database: The application strictly uses MySQL 8.0 (`placement_portal_java`).
2. Do NOT start MongoDB. MongoDB is not used by the current architecture.
3. Do NOT run the legacy Node.js backend (`server/`). The active production backend is Java Spring Boot (`server-java/`).
4. Do NOT delete, drop, reset, or recreate the database.
5. Do NOT run seed scripts just to start the project. Existing student profiles, placement drives, and application records are preserved in MySQL.
6. Keep both backend (Terminal 1) and frontend (Terminal 2) terminals open while using the application.
7. Closing the browser does not stop the backend or frontend servers.
8. Do not terminate an existing process on port 5000 without verifying whether it is the active Spring Boot backend.
9. Ensure that both `JWT_SECRET` and `PLACEMENT_APP_PASSWORD` environment variables are properly set in Terminal 1 before executing `.\mvnw.cmd spring-boot:run`.
10. Resume Storage: Uploaded resumes are stored in the decoupled `storage/resumes` directory (configurable via `RESUME_STORAGE_PATH`). Existing legacy resumes are automatically synchronized.

Project: Student Placement Management Portal
Frontend: React + Vite (Port 3000)
Backend: Java Spring Boot (Port 5000)
